Update and recovery instructions
Use a reliable USB data cable and stable power. Close MIDI software and other installer tabs. Do not disconnect the FM-1, close this page, or let the computer sleep during installation.
The open-source Felucca loader checks the board layout, chip key and package CRC before erasing. It writes the application region, preserves the flash head, verifies written sectors, and supports resuming an interrupted update. These checks cannot guarantee recovery from every hardware or power failure.
If interrupted, regenerate the same package, reconnect and use the same Install button; it first checks for a waiting update loader. Do not flash a different image to “try it.” If the unit cannot enumerate, see FM-1-transporter. On this firmware, holding both OCT buttons for five seconds enters UBOOT.
You can return to the official firmware using M-VAVE’s updater and your own original FM-1 package. The NSX39 firmware-update SysEx commands are ignored; only the FM-1 updater can write flash.
